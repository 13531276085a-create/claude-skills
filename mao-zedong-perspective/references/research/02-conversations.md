# Agent 2: 毛泽东对话与演讲中的思维方式

## 核心对话模式

### 1. 与埃德加·斯诺的访谈（1936-1970年间多次）
**思维特征**：
- 用坦诚和幽默化解外界误解——主动承认失败反而增强可信度
- 将个人经历融进更大的历史叙事中
- 「一切反动派都是纸老虎」（1946年与斯特朗的谈话）——用极简比喻概括复杂战略判断
- 纸老虎论核心思维：从外表看强大（原子弹+美式装备），从内在看脆弱（脱离人民+非正义+远离本土）

### 2. 延安文艺座谈会（1942）
- 开篇设问框定讨论范围：「我们的文艺是为什么人的？」
- 立场决定观点——明确价值排序
- 普及与提高的辩证关系

### 3. 遵义会议前后（1935）
- 在军事失败中抓住本质：不是兵力不够，是战略错了
- 用事实而非意识形态争论来说服
- 会前大量一对一沟通，建立共识后再上会——「会前工作」比「会中表现」更重要
- 只聚焦于军事路线——找准可以改变的突破口

### 4. 重庆谈判（1945）
- 「以革命的两手对付反革命的两手」
- 谈判中出让部分地盘换取政治主动——舍得割肉，换取全局优势
- 去了重庆本身就是一种胜利——行动本身就是最好的宣传

### 5. 对党内分歧的处理方式
- 「惩前毖后，治病救人」——批评的目的是帮助，不是消灭
- 「团结—批评—团结」公式
- 不急于定性——先观察，等矛盾充分暴露后再处理

## 即兴思维特征

| 特征 | 表现 |
|------|------|
| 类比能力极强 | 用日常事物解释复杂概念 |
| 善于反问 | 用反问瓦解对方的前提 |
| 先定性后展开 | 先给结论再给论据 |
| 历史感 | 把眼前问题放在大历史中定位 |
| 矛盾转化 | 指出当前阶段正在向下一阶段过渡 |
