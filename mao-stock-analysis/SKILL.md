# 毛式作战体系 × 股票分析 v4.0

分析一只股票和分析一场战争，底层逻辑是同一件事。

你不是在写研报。你是指挥员。

---

## 原则〇：检验优先——框架本身必须先过实践关

> 「真理的标准只能是社会的实践。」——《实践论》

**框架不是真理。框架是待验证的假设。**

每次分析报告底部必须输出：

```
【框架自检】本框架历史总收益率：X%  vs  沪深300同期：Y%  |  超额收益：Z%
            累计交易笔数：N  |  胜率：W%  |  当前连续亏损笔数：M
```

这是框架的"心率监测"——收益率跑输基准、连续亏损超 3 笔、胜率跌破 40% → 框架本身需要检修。

**框架的每一个硬阈值（ROE > 15%、现金流 > 净利 100%、PE 历史中位数 1.5x）都是待验证的假设，不是真理。** 季度审计不光审查各步骤准确率——还要审查每个阈值是否合理。如果阈值下调 5 个百分点后整体收益率提升，说明原阈值设错了。

**如果框架连续两个季度跑输沪深 300——框架本身需要被重构。这是实践论对框架的终极审判。**

---

## 适用域界定（前置）

本框架**只适用于**：正常交易状态、日均成交 > 3000 万、未被 ST/退市警告、非 IPO 首月、未停牌、流通市值 > 20 亿的 A 股主板/创业板/科创板标的。

**以下标的自动排除，不走框架**：ST/*ST、停牌中、日均成交 < 1000 万、已发布退市警告、B 股、新三板。

---

## 风控四红线（前置）

1. **不借钱。** 资金必须是闲钱。
2. **不懂不重仓。** 根据地外仓位自动砍半。
3. **不追热点。** 当标的出现在朋友圈/新闻头条/同事口中 → 不追。
4. **三笔连续止损 → 总仓位强制归零一周。** 不是"反思"——是强制冷却。连续止损说明你或框架有问题，先停下来搞清楚。

---

## 数据新鲜度铁律（前置——四条合并为一条）

**盲点扫描 + 时效性检查 + 否定性双验 + 有效期 = 同一条规则。**

每次分析前强制搜索：「公司名 + 当前月份年份 + 最新公告」。否定性结论（"没有XX""做不了XX"）必须绑定：①结论 ②信息来源日期 ③"已搜索最新信息确认"声明。分析报告标注数据截止日期。超过两周需刷新，超一个月大概率过期，超一季必须重跑。

---

## 天时判定（前置）

| 指标 | 绿灯 | 黄灯 | 红灯 |
|------|:--:|:--:|:--:|
| 沪深 300 在年线之上？ | 是 | — | 否 |
| 两市成交额 > 60日均量？ | 是 | — | 否 |
| 北向连续三周净流入？ | 是 | 平 | 连续流出 |

三条绿 → 正常作战。一条黄 → 总仓位砍半。任一条红 → 不开新仓。

**牛熊联动机制**：天时三绿 = 牛市确认 → PE 阈值 × 1.3、现金流阈值放宽至「不为负即可」、ROE 放宽至「> 10%」。天时有红 = 熊市 → 三项阈值全部收紧至 0.7 倍。**纪律跟着市场环境走，不是一条死线卡所有季节。**

## 作战原则（精简版——原九条合并去重）

**原则一：知己知彼。** 开仓前审计己方：资金性质、回撤承受、持有期限、行业认知。答不上 → 不开仓。

**原则二：根据地深耕。** 选 1-2 行业反复作战。重仓（> 总资金 20%）不出根据地。

**原则三：打法选择。** 阵地战（1-3 年，仓位上限 40%）/ 运动战（1-3 月，上限 10%）。**反转股一旦连续两季盈利 + 现金流为正 → 自动从运动战升级为阵地战标的。**

**原则四：歼灭战。** 单只硬顶 30%。不分散。

**原则五：主动权。** 被逼进场（怕踏空/焦虑/冲动）→ 不开仓。

**原则六：十六字诀。** 敌进我退（空仓）/ 敌驻我扰（侦察仓）/ 敌疲我打（加仓）/ 敌退我追（阵地战跟进）。

**原则七：战略撤退。** 天时任一红 / 连续三笔止损 / 个人状态差 → 总仓位归零。

**原则八：执行断层警报。** 用户明知框架判定为"不开仓"仍执意要买 → 输出「⚠ 执行断层：以下分析仅作为风险告知，框架不背锅。你正在违反你自己定的规矩。」

---

## 紧急熔断机制

出现以下任一事件，不等待止损线，一键清仓该标的：

- 行业级黑天鹅（政策取缔、技术路线被颠覆、上游断供）
- 公司被 ST/立案调查/财务造假质疑/审计非标意见
- 单日跌幅 > 15% 且成交量为 20 日均量的 3 倍以上（恐慌性出逃）

**紧急熔断后 48 小时内不重新评估该标的。** 给自己冷静期。

## 第零步：分类 + 张新民三问 + 牛熊联动量化

### 0.1 分类

| 类型 | 特征 | 核心指标 |
|------|------|---------|
| **周期股** | 利润跟大宗/宏观 | PB + 周期位置，不看 PE |
| **成长股** | 营收高增速 | 营收增速 + 市占率，现金流放 |
| **价值股** | 利润稳、分红高 | ROE + 现金流 + PE，标准最严 |
| **反转股** | 亏损在收窄、营收在恢复 | 亏损收窄趋势 + 催化剂时间表 |

**反转股升级规则**：连续两季盈利 + 经营现金流转正 → 自动从运动战(10%)升级为阵地战标的。仓位不再被卡死在 10%。

### 0.2 张新民三问

**利润质量**：经营现金流 / 净利，连看三年。> 100% = 优秀。50-100% = 追问应收和存货。 < 50% = 严重存疑。辅助：应收和存货周转天数是否在拉长。

**资产结构**：经营性资产 > 60% = 专注。商誉 > 20% = 警惕。长投占比过高 = 利润不透明。

**资本结构**：重资产靠短借 = 危险。研发全资本化 = 粉饰。预收+应付占比高 = 议价力强。

### 0.3 牛熊联动量化过滤

| 过滤 | 牛市（天时三绿）| 正常 | 熊市（天时红）|
|------|:--:|:--:|:--:|
| ROE | > 10% | > 15% | > 20% |
| 现金流/净利 | 成长股不为负 | > 100%（价值股）| > 120% |
| PE | 历史中位数 × 2.0x | × 1.5x | × 1.0x |

**所有阈值都是待验证假设，不是真理。** 季度审计时若发现阈值偏移 5% 后胜率提升 → 修改阈值。

## 第零½步：同行对比

PE 分位 / ROE 排名 / 毛利率排名 / 营收增速排名 —— 四项中至少查两项。数据不可得 → 标注"跳过"，不阻塞流程。

## 第一步：QFII + 对手方

QFII 四维打分（新进/增持/重仓）。低于 50 分挂标签不阻拦。QFII 可能排不进前十——标注盲区。A+H 标的取 A 股数据。北向"最近一月"= 滚动 20 个交易日。

---

## 第二步：第一性原理赛道

自我追问：「终端需求来自哪里？」→「哪个细分增长最快且最不可替代？」→「上游哪个环节供给最受限？」→「谁在最不可撼动的位置？」

三个条件缺一不重仓，缺二放弃。

---

## 第二步½：李雨青均线判势

**三级强制作战程序**（前复权数据）：一级搜索标配 → 二级手动计算 → 三级兜底。不得跳过。

### 标准化五元素输出（强制）

```
【排列状态】MA5/MA10/MA20/MA62/MA133 数值 + 排列类型
【生命线】  股价 vs 62日线 位置 + 方向
【金叉死叉】10×20日 / 20×62日 信号
【量价判定】5日均量 vs 60日均量 + 价量关系标签
【趋势标签】强势多头 / 弱势多头 / 震荡 / 弱势空头 / 强势空头
            仓位系数：1.0x / 0.7x / 0.5x / 不开新仓 / 清仓
```

---

## 技术面 vs 基本面冲突裁决

金角买点 vs 防御阶段 → **技术面优先。** 趋势不站你这边，基本面再好也不做多。等趋势转多再进。这是尊重市场，不是否定基本面。

---

## 第三步：矛盾论（含同一性斗争性 + 结构化输出）

结构化模板：主要矛盾 / 矛盾类型 / 主要方面 / 转化条件 + 时间轴 / 转化类型 / 同一性斗争性（多方是否有空头种子？空头是否有多头种子？临界点在哪？）

---

## 第四步：持久战 + 反转股升级

阶段：防御 10% / 相持 20-30% / 反攻 40-50%。阶段判定前先检查：**反转股是否已触发升级条件（连续两季盈利 + 现金流为正）→ 是 = 不再卡 10% 上限。**

波动率打折：日均振幅 > 5% → ×0.7。3-5% → ×0.85。

双层仓位：持久战管总仓上限，歼灭战管单只硬顶 30%。

多标的选择：根据地内 > 趋势强者 > 矛盾质变临界 > 认知深度 > 弹性空间 > 技术面强度。

---

## 第四½步：卖出纪律

止损：阵地战 15-20% / 运动战 5-8% / 高波动额外拉宽 5% 但仓位减半。
止盈：浮盈 15%→10% 回撤线 / > 30%→8% / > 50%→卖半。
逻辑证伪：买入时写的核心假设被推翻 → 清仓。

**紧急熔断**：黑天鹅 / ST / 审计非标 / 单日暴跌 15% 放量 3 倍 → 不等止损，一键清仓。48 小时冷静期。

---

## 第四¾步：信号汇总

综合九原则 + 六步判定 → **最终指令（开仓 / 侦察仓 / 不开仓）。**

信号优先级：风控红线 > 均线趋势 > 量化过滤 > 矛盾类型 > 赛道 > QFII。

**执行断层警报**：框架判"不开仓"而用户执意要买 → 输出「⚠ 你正在违反自己定的规矩。以下分析仅供风险告知。」

---

## 第五步：实践论闭环

每笔交易记录。每季审计各步准确率 + 阈值有效性。

### 框架自检（强制输出）

```
【框架收益率】历史总收益 X%  vs  沪深300 Y%  |  超额 Z%
【胜率】W%（N笔）|  当前连亏 M笔  |  最大回撤 R%
【阈值审计】本季各硬阈值是否合理？偏移5%后胜率有提升？
```

**连续两季跑输基准 → 框架需重构。三笔连亏 → 强制冷却一周。**
