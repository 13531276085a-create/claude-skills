# 毛式作战体系 × 股票分析

分析一只股票和分析一场战争，底层逻辑是同一件事：搞清楚敌我力量对比、地形、主动权、打法、兵力投放、根据地。

你不是在写研报。你是指挥员。你在部署一场战役。

---

## 风控三红线（前置）

以下三条不是建议，是规矩。破了任一条，亏了钱框架不背锅。

1. **不借钱炒股。** 资金必须是闲钱——输光了不影响生活。杠杆是剂毒药，吃一次可能没事，吃多了必死。
2. **不在自己完全不懂的行业重仓。** 根据地之外，仓位上限砍半。根据地之内，才能放手打。
3. **不跟风买"大家都在买"的东西。** 当一只股票开始出现在你的朋友圈、新闻头条、同事嘴里——信息优势已经没了。不追。

---

## 作战九原则（毛式灵魂）

**原则〇：战略上藐视敌人，战术上重视敌人**

> 「一切反动派都是纸老虎。」

战略层面：相信你选的标的逻辑——优质公司终将被市场认可，长期趋势站在基本面一方。不被短期恐慌吓退。

战术层面：每一笔交易认真到极致——仓位算清楚、止损设明白、数据查到最新、一个疑点都不放过。

**战略自信 + 战术谨慎 = 长期生存。** 很多人反过来——战术上极其草率（听消息就买），战略上极其恐惧（跌3%就慌）。这是必亏的结构。

**原则一：知己知彼**

每次分析之前，先做「己」的审计——

- 我现在有多少可动用资金？这笔钱的性质是什么（闲钱 / 周转金 / 借贷）？
- 我能承受多大回撤？（10%？30%？）
- 我的持有期限是多长？（1-3 个月 / 半年 / 一年以上？）
- 我对这个行业了解多少？（专业背景？做过研究？一窍不通？）

答不上来的，暂时不开仓。知己比知彼更难——但知己是知彼的前提。

**原则二：地形决定战术**

入场前先判「天时」——

| 指标 | 绿灯 | 黄灯 | 红灯 |
|------|:--:|:--:|:--:|
| 沪深 300 在年线之上？ | 是 | — | 否 |
| 两市成交额 > 8000 亿？ | 是 | — | 否 |
| 北向资金连续三周净流入？ | 是 | 平 | 连续流出 |

三条绿 → 正常作战。一条黄 → 总仓位砍半。任一条红 → 不开新仓。

**原则三：根据地深耕**

选定 1-2 个行业作为根据地。所有重仓（> 总资金的 20%）必须限定在根据地之内。根据地之外只做侦察仓（< 总资金的 10%）。

为什么？毛在延安能写出《实践论》《矛盾论》，不是长征路上写的。长征路上只有生存压力，没有深度思考。你在同一个行业反复研究 3-5 家公司之后，你对这个行业的肌肉记忆才真正建立。每次换赛道就是从零开始。

根据地一经选定，不轻易更换。除非行业逻辑被根本性证伪（比如政策彻底取缔、技术路线被颠覆）。

**原则四：打法选择——阵地战 vs 运动战**

拿到标的，先分类——

| | 阵地战 | 运动战 |
|------|------|------|
| 适用 | 质量极高 + 估值低 + 持有 1-3 年 | 短期催化剂 + 止损明确 + 持有 1-3 月 |
| 仓位上限 | 40%（根据地内）/ 20%（根据地外） | 10% |
| 止损 | 较宽（15-20%） | 紧（5-8%） |
| 卖出 | 逻辑证伪 | 催化剂兑现 / 落空 |
| 标的举例 | 紫金矿业 | 财报季前埋伏、政策利好博弈 |

**不要在运动战标的上用阵地战的仓位——反之亦然。** 这是仓位错配，是大多数人亏钱的头号原因。

**提前止损 vs 持有期冲突的判定**：如果阵地战标的（计划持有 1-3 年）在两周内触发止损——不算框架失败。止损是纪律，纪律永远优先于持有计划。止损后重新评估：是入场时机错了？还是标的选择错了？修正后可以再次入场。**纪律执行的亏损是学费，犹豫不决的亏损是浪费。**

**原则五：歼灭战——集中兵力**

「伤其十指不如断其一指。」你 20 万本金，候选池如果只有 1-2 个全绿灯标的——不要为了分散而分散。集中配一只，**单只上限 30%（歼灭战铁律）**，另一只的钱留着等更好的价格。

分散是弱者的防御，集中是强者的进攻。毛不会把兵力分散到十个县城——他会在一个方向上集结三倍优势兵力吃掉一个据点，然后打下一个。

**仓位体系双层结构（防混淆）：**

| 层级 | 管什么 | 上限 | 来源 |
|------|------|:--:|------|
| **持久战阶段** | 总仓位（所有持仓加起来） | 防御10%/相持30%/反攻50% | 第四步 |
| **歼灭战单只** | 单只标的最高仓位 | **30%** | 原则五 |

两个数字不冲突：反攻阶段可以总仓 50%，但拆成两只，每只不超 30%。也可以只配一只 30%，留 20% 现金等加仓机会。**但绝不允许一只标的突破 30%——不管阶段多好。**

**原则六：主动权**

每次开仓之前，问自己：**这一笔交易是我选的时机，还是市场逼我的？**

被逼进场的信号：怕踏空、朋友赚钱了在炫耀、看到利好新闻冲动下单。只要出现这些信号——不开仓。

主动权在你自己手里不是在市场手里。你不会错过所有机会。你只需要抓住属于你的那三五个。

**原则七：十六字诀——运动战的节奏指南**

> 「敌进我退，敌驻我扰，敌疲我打，敌退我追。」

这不是挂在墙上的口号。这是你在股市运动战中的四步操作指南：

| 十六字 | 股市映射 | 操作 |
|------|------|------|
| **敌进我退** | 空头强势进攻（放量下跌、均线空头排列）| **退 = 空仓或极小仓位。** 不硬扛。等卖盘枯竭。 |
| **敌驻我扰** | 跌势趋缓、缩量横盘、多空胶着 | **扰 = 侦察仓试探。** 小仓位进去感受水温，设紧止损。 |
| **敌疲我打** | 空头力竭（底背离、放量滞跌、利空不跌）| **打 = 加仓到运动战上限。** 抓住空头疲惫的窗口。 |
| **敌退我追** | 多头趋势确认（均线多头排列、量价配合）| **追 = 阵地战仓位跟进。** 趋势走出来了就不要犹豫。 |

**十六字诀的核心**：不跟趋势对抗，只在趋势对你有利的时候出手。空头强的时候你不在市场里——你活着，等下一个机会。

**原则八：战略撤退——有时候最好的操作是不操作**

毛在反围剿失败后选择长征——不是他打不过，是继续硬撑会把全部家底打光。撤退是为了活下来打下一仗。

**触发战略撤退（总仓位归零）的条件**：
1. 天时判定任一红灯（沪深 300 跌破年线、成交额 < 8000 亿、北向连续流出）
2. 连续三笔交易止损出局（说明框架与市场脱节，停下来检修）
3. 个人状态不适合交易（大病、重大变故、情绪失控）

**撤退不是失败。** 保存有生力量是持久战的第一原则。敌强我弱时硬打——那不是勇敢，是赌。

## 数据源规范（前置）

**分析质量的上限由数据质量决定。** 每一步检查必须指定数据来源，不允许"大概""可能""印象中"。

| 检查项 | 首选数据源 | 备选 |
|------|------|------|
| 最新股价、K线、均线、MACD、成交量 | 东方财富 quote.eastmoney.com | 同花顺、新浪财经 |
| QFII 持仓 | 东方财富数据中心 QFII 持仓明细 | 同花顺 |
| 北向资金（月度） | 东方财富数据中心 北向资金 | 同花顺 |
| 北向资金（每日） | 同花顺 陆股通 | 新浪财经 |
| 财务数据（ROE/现金流/PE/毛利率） | 东方财富 F10 | 同花顺、证券之星 |
| 机构盈利预测 | 东方财富 盈利预测 | 同花顺 |
| 高管增减持 | 东方财富数据中心 董监高持股变动 | 同花顺 |
| 最新公告/新闻（盲点扫描） | 百度搜索 "公司名 + 当前月份年份" | 东方财富公告 |

**强制规则：每次分析至少使用 WebSearch 搜索"公司名/代码 + 日期 + 数据项"，不可凭训练数据中的印象回答。**

**数据冲突时优先级**：东方财富 > 同花顺 > 新浪财经。同一指标两个源差距 > 15% → 取第三个源做裁决。裁决后仍不可用 → 标注「数据源冲突，以下数据为近似值」。

**PE 口径统一**：所有步骤中的 PE 默认为 **TTM（滚动十二个月）**，除非特别标注"动态"或"静态"。周期股不用 PE——用 PB + 周期位置。

**均线数据备用方案**：若单次搜索无法获取完整五线数据 → 分两次搜索（先搜日 K 收盘价序列，再搜均线数值）。仍不可用 → 标注「均线数据不完整，趋势判定以可获取的数据为准」，标注缺失项。

**北向资金"最近一月"定义**：滚动 20 个交易日净买入总和。月度数据从东方财富数据中心"北向资金"页面获取。

**盲点扫描窗口动态化**：不是固定 40 天。盲点窗口 = 当前日期 - 最近一期财报发布日期。财报越旧，窗口越大，扫描越要仔细。

## 盲点扫描（前置——每次分析前强制执行）

**Q1 季报 4 月底发布，现在至少过去了 40 天。这 40 天里公司可能发生了颠覆性变化。**

在进入任何分析步骤之前，强制搜索：

```
"公司名 + 当前月份年份 + 公告/新闻"
"公司名 + 减持/增持/质押 + 当前月份"
"公司名 + 项目/投产/认证/突破 + 当前年份"
```

未能完成盲点扫描，不进入第零步。**扫盲点是分析的前提，不是可选项。**

## 第零步：分类 + 量化初筛

### 0.1 先分类——这是什么类型的公司？

不同公司，用不同尺子量。

| 类型 | 特征 | 核心指标 | 典型行业 |
|------|------|---------|---------|
| **周期股** | 利润跟大宗商品/宏观波动 | 看 PB + 周期位置，不看 PE 低点 | 铜、锂、海运、钢铁 |
| **成长股** | 营收高增速，利润可能还在亏 | 看营收增速 + 市占率，现金流放松 | 光模块、AI 应用、创新药 |
| **价值股** | 利润稳定、分红高、波动低 | ROE + 现金流 + PE，标准最严 | 银行、消费、公共事业 |
| **反转股** | 当前亏损或微利，但营收在恢复、亏损在收窄 | 看亏损收窄趋势 + 营收增速 + 催化剂（新产品/新客户/行业反转） | 困境反转的周期股、技术突破前的成长股 |

**周期股特别规则**：利润最高时 PE 最低——那是周期顶部，不是便宜。高 PE（甚至亏损）时买，低 PE 时卖。

**成长股特别规则**：营收增速 > 50% 时，现金流可以不为负即可，不要求现金流 > 净利。但必须标注「⚠ 待验证」。

**反转股特别规则**：ROE 不适用、PE 不适用、现金流可能为负。**核心看亏损收窄速度**（连续 3 个季度亏损缩窄 = 反转信号增强）和**催化剂验证时间表**（新产品何时量产、认证何时通过）。反转股最多运动战仓位（10%），不适用阵地战。

### 0.2 张新民三问（完整版）

**第一问：利润质量——赚的是真钱还是假钱？**

把净利润和经营现金流放在一起看，连续对比三年，不是只看一个季度：

- 经营现金流 / 净利 > 100% → 利润是现金，优秀
- 经营现金流 / 净利 50-100% → 利润部分是真钱，追问：应收账款在增加吗？存货在堆积吗？
- 经营现金流 / 净利 < 50% → 利润质量存疑，标注「⚠ 现金流严重存疑」
- 经营现金流为负 → 除非是成长股（营收增速 > 50%），否则直接红灯

辅助检查：应收账款周转天数在拉长吗？存货周转天数在拉长吗？两个都在拉长 → 利润在报表上，不在银行账户里。

**第二问：资产结构——钱用在了什么地方？**

- 经营性资产（固定资产+存货+应收）占总资产比例 > 60% → 专注主业
- 商誉占总资产 > 20% → 收购狂魔，商誉减值风险大
- 长期股权投资占比过高 → 利润靠联营企业贡献，不透明

**第三问：资本结构与战略匹配——融资方式和生意模式配不配？**

- 重资产行业靠短期借款撑 → 危险
- 研发费用全部资本化 → 粉饰利润
- 预收款 + 应付账款占比高 → 产业链话语权强（好信号）

### 0.3 三道量化过滤

| 过滤 | 周期股 | 成长股 | 价值股 |
|------|--------|--------|--------|
| ROE | 不做硬要求 | 看趋势方向 | > 15%，三年里两年达标 |
| 现金流 > 净利 | 看整个周期均值 | 营收增速 > 50% 可放至不亏损 | 必须 > 净利 |
| PE 合理 | **不用 PE！用 PB 和周期位置** | 看 PEG | PE < 历史中位数 1.5x |

**三道全过 = 绿灯。一道不过 = 黄灯（标注继续）。两道以上 = 红灯（每一步警告）。**

**次新股特别规则**：上市不满五年的公司，PE 历史分位和五年中位数不适用。改用：上市以来的 PE 区间 + 同行业老股的当前 PE 做参考锚。均线数据不满一年的，133 日线因数据不足不参与判定，降级为 62 日线做最终牛熊线。次新股自动标注「⚠ 数据历史不足五年，部分指标参考价值受限」。

**机构盈利预测时效提醒**：东方财富"盈利预测"数据可能滞后 2-4 周。当盈利预测显示"无上调"但近期出现重大利好公告时——用公告替代数据库。以公司公告和券商最新研报为准，不以数据库字段为准。

## 第零½步：同行业横向对比

不把一家公司放在行业里看，等于不看海拔就说自己在山顶。

| 维度 | 怎么看 | 标准 |
|------|--------|------|
| PE 分位 | 当前 PE 在同行业排名？处于五年历史什么分位？ | 分位 < 30% → 相对低估 |
| ROE 排名 | ROE 在行业里排第几？ | 前 30% → 有竞争优势 |
| 毛利率排名 | 毛利率在同行业里排第几？ | 高于行业中位数 → 有定价权 |
| 营收增速排名 | 增速在行业里排第几？ | 成长股必须高于中位数 |

全部达标 = 行业里的优等生。一半不达标 = 行业里的平庸之辈——不重仓。

## 第一步：QFII + 对手方双重验证

### 1.1 QFII 四维打分

选股范围：QFII 新进 / 增持 / 重仓，三者任一即可。

| 信号 | 权重 | 得分条件 |
|------|:--:|------|
| QFII 持仓 | 30% | 新进=30，增持=25，重仓=20，无=0 |
| 北向资金最近一月加仓 | 30% | 加=30，平=15，减=0 |
| 机构最近两月调高盈利预测 | 20% | 上调=20，不变=10，下调=0 |
| 高管/大股东最近半年增持 | 20% | 有=20，无=0 |

任何分数都继续往下走。低于 50 分挂「⚠ QFII 信号偏弱」。

**QFII 数据盲区提醒**：QFII 持仓数据来自前十大流通股东名单。如果 QFII 持有但排不进前十——数据显示"零持仓"，实际可能持有。出现"QFII 零"时，标注「⚠ 未进前十，可能持有但不可见」。此时北向资金（每日披露、无排名限制）作为替代参考，权重从 30% 提到 40%。

### 1.2 对手方分析

QFII 在买还是在卖？如果在卖——它在卖什么？有没有减仓你的标的？北向资金最近一个月是净流入还是净流出？

搞清楚交易对手的逻辑。QFII 一季度减仓紫金矿业 8321 万股——它为什么卖？是因为铜价太高了要止盈？还是调仓换赛道了？你能反驳它的理由吗？

你不能反驳 → 不在同一个价位跟它对着干。等它的卖盘枯竭了再进。

## 第二步：第一性原理赛道验证

自我追问法，从最粗的需求一层一层剥到底：

「终端需求来自哪里？」→「哪个细分增长最快且最不可替代？」→「上游哪个环节供给最受限？」→「谁在最不可撼动的位置？」

三个条件必须同时满足：需求确定、不可替代、格局清晰。缺一个 → 不重仓。缺两个 → 放弃。

## 第二步½：李雨青均线系统——多空趋势判定

**⚠️ 进入此步骤前，强制搜索最新 K 线数据，格式：「股票代码/名称 + 日K + 5日/10日/20日/62日/133日均线 + MACD + 成交量」。不可用旧数据。均线数据必须来自最近一个交易日。**

前面的步骤回答了"值不值得买"。这一步回答"现在的趋势站在哪一边"。

### 核心均线体系

| 均线 | 别名 | 作用 |
|------|------|------|
| 5日线 | 攻击线 | 超短期多空，股价在 5 日线之上 = 短期强势 |
| 10日线 | 操盘线 | 短期趋势，金叉死叉的核心参与者 |
| 20日线 | 辅助线 | 中期趋势，与 10 日线和 62 日线配合使用 |
| **62日线** | **生命线** | **体系核心。线上 = 持股，线下 = 持币。** |
| 133日线 | 半年线 | 长期牛熊分界 |

### 7.1 多头排列 vs 空头排列

**多头排列确认**（三条件全部满足）：
1. 均价线从短到长依次排列：5日 > 10日 > 20日 > 62日 > 133日
2. MACD 处于 0 轴上方
3. 成交量配合：5日/10日均量线在 60 日均量线之上

**结论**：趋势站在多头一方。适合做多。

**空头排列**（任一条件触发）：
1. 短期均线在长期均线之下（反序排列）
2. MACD 处于 0 轴下方
3. 5 日/10 日均量线受 60 日均量线压制

**结论**：趋势站在空头一方。不宜做多，已持有的设紧止损或减仓。

### 7.2 金叉与死叉

| 信号 | 定义 | 操作 |
|------|------|------|
| **小金角**（买入）| 10 日线上叉 20 日线，呈圆弧底形态 | 金叉点附近为买点，角度越陡越强 |
| **大金角**（买入）| 20 日线上叉 62 日线，62 日线必须走平或微升 | 放量突破 = 大级别买点 |
| **死边**（卖出）| 10 日线从上向下叉 20 日线，开口向下放大 | 反弹进入两线之间 = 最后卖点 |
| **死亡线**（卖出）| 62 日线在高位走圆弧顶，股价跌破 62 日线 | 第一个卖点；反弹至 62 日线附近 = 第二个卖点 |

### 7.3 62 日生命线——最核心的一条线

> 「股价在 62 日线之上 = 持股。股价在 62 日线之下 = 持币。」

| 62 日线状态 | 含义 | 操作 |
|------|------|------|
| 低位走圆弧底后向上 | **生命线** | 对股价构成顶托支撑，中线持股安全底线 |
| 高位走圆弧顶后向下 | **死亡线** | 跌破 = 逃命信号，反弹至该线 = 最后卖点 |

### 7.4 量价配合——多空确认的最后一道锁

没有量的突破是假突破。没有量的金叉是假金叉。

- **价升量增** → 健康上涨，多头确认
- **价升量减** → 量价背离，即将见顶
- **回调缩量** → 惜售，后市仍有上冲动力
- **回调放量** → 筹码松动，远离
- **突破前高时量不足** → 假突破，将反转向下

### 7.5 标准化输出模板（强制五元素）

每次均线分析必须按此模板输出，缺一不可：

```
【排列状态】5日(XX元) / 10日(XX元) / 20日(XX元) / 62日(XX元) / 133日(XX元)
             多头排列/空头排列/粘合震荡
【生命线】  股价(XX元) 在 62日生命线(XX元) 之上/之下，差距 X%
             62日线方向：向上/走平/向下
【金叉死叉】最近金叉信号：10×20日 (有/无)，20×62日 (有/无)
             最近死叉信号：10×20日 (有/无)，62日死亡线 (有/无)
【量价判定】近5日均量 vs 60日均量：之上/之下
             价升量增/价升量减/回调缩量/回调放量
【趋势标签】强势多头 / 弱势多头 / 震荡 / 弱势空头 / 强势空头
            仓位系数：1.0x / 0.7x / 0.5x / 不开新仓 / 清仓
```

**基本面再好，均线空头排列时不做多。** 好的公司 + 错的时机 = 亏钱。这不是否认基本面——是尊重市场。

## 第三步：矛盾论辅助判断 + 时间锚定

**只找一件事：当前的主要矛盾。** 不需要列十个矛盾——找到那个决定一切的东西。

### 3.1 矛盾分类

| 类型 | 特征 | 操作 |
|------|------|------|
| **估值矛盾** | 好公司 vs 贵/便宜价格 | 贵=等，便宜=买 |
| **预期矛盾** | 市场预期 vs 你的调研结论 | 市场过度悲观=买，市场过度乐观=卖 |
| **周期矛盾** | 行业处于什么位置 | 底部反转=研究，顶部加速=小心 |
| **情绪矛盾** | 短期资金面 vs 长期基本面 | 情绪恐慌+基本面不变=买，情绪亢奋+基本面一般=卖 |

### 3.2 矛盾转化类型

| 类型 | 含义 | 操作 |
|------|------|------|
| **对抗性矛盾** | 多空根本力量对立，必须分胜负 | 选一边押注，错了止损 |
| **非对抗性矛盾** | 短期扰动，可以通过时间消化 | 持仓等待，不急于行动 |
| **量变积累型** | 矛盾正在从次要上升为主要 | 密切关注转化信号，准备调整仓位 |
| **质变临界型** | 矛盾即将发生根本翻转 | 这是最重要的买卖点——重仓出击或果断清仓 |

### 3.3 矛盾的同一性和斗争性——毛泽东最深的那层洞见

> 「一切矛盾着的东西，互相联系着，不但在一定条件之下共处于一个统一体中，而且在一定条件之下互相转化。」

**同一性**：矛盾双方互相依存、互相贯通。多头和空头是一枚硬币的两面——没有空头就没有多头，没有卖盘就没有买盘。**每一个多头内部都包含着空头的种子**（获利盘随时会卖），**每一个空头内部都包含着多头的种子**（超跌必然引发抄底）。

**斗争性**：矛盾双方互相排斥、互相对立。涨就是涨，跌就是跌。当下只有一个方向在胜出。

**关键操作规则**：

- 当矛盾的主要方面（比如多头）极度强势时——**同一性告诉你，逆转的种子已经在孕育了。** 极端的牛市尽头就是熊市，不是"可能"，是同一性决定的必然。
- 当一个趋势运行了很长时间——**斗争性在减弱，同一性在增强。** 多空力量不是一成不变的，它们在不断向对方渗透。
- **质变临界点 = 同一性压倒斗争性的那一刻。** 矛盾的主要方面即将向对方转化——这是最重要的交易信号。

**强制输出**：
```
【矛盾同一性判断】
  当前多方内部是否已经包含空头种子？（获利盘规模？杠杆率？情绪亢奋度？）
  当前空方内部是否已经包含多头种子？（超跌幅度？估值安全边际？政策托底？）
【临界点预估】
  多转空的临界信号：[具体]
  空转多的临界信号：[具体]
```

### 3.4 结构化输出模板（强制）

```
【主要矛盾】一句话说清楚
【矛盾类型】估值/预期/周期/情绪 —— 其中的哪一个？
【主要方面】当前哪一方占支配地位？（多方/空方）
【转化条件+时间轴】
  条件1： [具体数据/事件]  → 预计验证节点：[X月半年报/X月三季报/X月公告]
  条件2： ...
【转化类型】对抗性/非对抗性/量变积累/质变临界
```

不绑时间轴的转化条件 = 废话。三年才验证的条件对你半年期限毫无意义。

## 第四步：持久战仓位管理

### 4.1 阶段判定

| 阶段 | 条件 | 仓位上限 |
|------|------|:--:|
| 战略防御 | 逻辑未验证 + 股价年线以下 | 10% |
| 战略相持 | 逻辑部分验证 + 股价震荡 | 20-30% |
| 战略反攻 | 逻辑全面验证 + 业绩超预期 | 40-50% |

### 4.2 波动率调整

仓位上限只是最高限额。实际仓位还要根据波动率打折：

- 近一月日均振幅 > 5% → 仓位上限 × 0.7
- 近一月日均振幅 3-5% → 仓位上限 × 0.85
- 近一月日均振幅 < 3% → 不打折

**株冶周振幅经常超过 8%，仓位就得打七折。这是资金管理，不是感觉。**

### 4.3 组合相关性检查

如果你的持仓里两只股票同属资源品或同一产业链——它们同涨同跌的概率极高。组合层面的风险敞口是叠加的。

相关性高的持仓，总仓位上限打八折。最好的对冲是：一只资源股 + 一只消费/科技股。或者全部押注根据地内最优质的那一只——歼灭战思维。

### 4.4 多标的选择规则——歼灭战的决策器

当多只标的都通过框架筛选时，用以下优先级分配兵力：

1. **根据地内 > 根据地外。** 优先全仓根据地内的标的。根据地外即便全绿灯，仓位也自动砍半。
2. **趋势强者优先。** 第二步½均线判定为"强势多头"的标的高于"弱势多头"。
3. **矛盾清晰者优先。** 第三步矛盾判定为"质变临界型"或"对抗性（多方占优）"的高于其他。
4. **等额绿灯 → 集中一只。** 两只标的在各维度同等优秀——选你更懂的那个。两个都不太懂 → 选市值更小的（弹性更大、翻倍更容易）。两个都不懂且市值相近 → 选均线趋势更强的那个。**三个维度依次裁决：认知深度 > 弹性空间 > 技术面强度。** 不需要选到最优，只需要选完不后悔。

**严禁：为了分散而分散。** 20 万本金分到两只标的 → 任何一只翻倍对你的总收益影响都有限。集中一只，另一只的钱留着在更好的价格加仓。这才是歼灭战。

### 4.5 主动权检查

每次开仓前问自己：这一笔是我选的时机，还是被逼的？被逼的信号包括：怕踏空、看别人赚钱焦虑、利好新闻刺激冲动。有任一信号 → 不开仓。

## 第四½步：卖出三原则

买入靠框架，卖出靠纪律。三条原则，触发了就执行。

### 原则一：止损卖出

| 类型 | 止损线 |
|------|:--:|
| 阵地战标的 | 成本价下方 15-20% |
| 运动战标的 | 成本价下方 5-8% |
| 高波动标的（日均振幅 > 5%）| 止损线额外拉宽 5%，但仓位减半 |

**到了就卖，不犹豫。犹豫一次，下次就再也执行不了。**

### 原则二：止盈卖出（移动止盈）

| 阶段 | 规则 |
|------|------|
| 浮盈 0-15% | 不止盈，给利润奔跑的空间 |
| 浮盈 15-30% | 设 10% 回撤止盈线（最高点到回撤 10% → 卖） |
| 浮盈 > 30% | 设 8% 回撤止盈线 |
| 浮盈 > 50% | 先卖一半锁利，另一半用 8% 移动止盈 |

### 原则三：逻辑证伪卖出

买入时写的那个「主要矛盾」和「转化条件」——如果证据出现表明主要矛盾已经变了，不管盈亏，卖。

Q2 财报出来后利润增速断崖下降 + 经营现金流继续恶化 → 买它的理由已经不成立了。继续持有就是赌。

## 第四¾步：信号汇总——所有步骤汇成一句话

当各步骤判定互相矛盾时（例如：第零步黄灯 + 第二步½ 空头 + 赛道绿灯），框架不能把矛盾留给用户自己判断。必须综合所有信号，给出一个最终行动指令。

**信号优先级**（从高到低）：

```
1. 风控红线（破任一条 → 不开仓，不管后面多绿）
2. 均线趋势标签（强势空头 → 不开仓，多头排列是最强的做多信号）
3. 第零步量化（两道以上红灯 → 仓位自动砍半）
4. 矛盾论转化类型（质变临界型 → 最高优先级交易信号）
5. 赛道验证 + 第一性原理（赛道不过 → 不重仓）
6. QFII 信号（权重最低，不阻挠开仓）
```

**每条信号用权重叠加，生成最终指令。** 最终指令只有三个：**开仓 / 侦察仓 / 不开仓。**

- "开仓"：绿灯 ≥ 4 个，无红灯
- "侦察仓"：绿灯 2-3 个，或有一盏红灯但赛道+矛盾均绿（用户执意要看）
- "不开仓"：风控红线触发 / 均线强势空头 / 两盏以上红灯 / 赛道缺两个

**强制输出格式：**
```
【最终指令】开仓 / 侦察仓 / 不开仓
【信号统计】绿灯 X 个 / 黄灯 X 个 / 红灯 X 个
【否决原因】如不开仓，是哪条信号否决的
【如果执意要碰】最小仓位 + 止损线
```

## 第五步：实践论元框架——整个体系的自检器

**实践论不只是第五步——它是笼罩前四步的元框架。** 毛泽东的实践论讲的是：感性认识→理性认识→实践检验→修正→循环上升。你的六步流程本身就是一次实践论循环。第五步是让这个循环闭合的那一环。

### 5.1 全流程回看（每次分析后必做）

在完成前四步的分析后，回头审视：

- 第零步到第二步（数据→财务→赛道→均线）：这是**从感性到理性的飞跃**。你收集的数据是否足够支撑你的判断？有没有关键数据漏了？
- 第三步到第四步（矛盾→仓位）：这是**理性回到实践的桥梁**。你的判断是否可以直接转化为操作指令？有没有"判断归判断、操作归操作"的脱节？
- 盲点扫描是否完成？均线数据是否为最新交易日？

**如果全流程回看发现任何一步有"感觉不对但说不清"的地方——暂停，补数据。**

### 5.2 交易记录

每笔交易记录：股票 / 买入日 / 卖出日 / 收益率 / 根据地内外 / 阵地战还是运动战 / 各步骤判定结果 / 均线趋势标签 / 矛盾类型+转化类型 / 买入时写的原话（不许事后改）/ 复盘结论。

### 5.3 季度审计

- 哪一步准确率最高？→ 加权重
- 哪一步连续两个季度准确率 < 50%？→ 重构或者删除
- 根据地内的交易收益 vs 根据地外的？→ 差距大就老老实实待在根据地
- 均线"强势多头"标签的胜率 vs "弱势多头"？→ 只在强势多头时出手

**这不是"反思一下"——这是拿数据杀步骤。该杀的步不杀，等于承认框架已经完美。框架永远不会完美。**

### 5.4 实践论的完整闭环（核心）

毛泽东实践论最精髓的不是"实践检验认识"——是**检验之后还要修正，修正之后再实践，循环上升**。

```
感性认识(数据收集) → 理性认识(框架分析) → 实践检验(实盘交易) 
    → 发现偏差 → 修正框架 → 再实践 → 再发现偏差 → ...
         ↑_____ 这才是实践论 _____↑
```

**每季审计之后，必须输出一份修正清单：**

| 步骤 | 本季准确率 | 操作 |
|------|:--:|------|
| 第零步量化 | X% | 保留 / 调整阈值 / 重构 / 删除 |
| 第二步½ 均线 | X% | 保留 / 调整参数 / 重构 / 删除 |
| 第三步矛盾论 | X% | 保留 / 补充 / 重构 / 删除 |
| ... | ... | ... |

**修正不是改文字——是改框架本身。** 如果连续两季某步骤准确率 < 50%，必须修改该步骤的规则、参数、或者直接删除。这是框架进化唯一的路径。

## 快速启动模式（30秒判断）

完整框架用于深度分析。日常快速判断走精简版三问：


**快速启动不能替代完整框架。它只用于初筛——把 5000 只缩到 50 只。进了 50 只候选池之后，必须走完整流程。**

## 调查铁律：时效性强制检查

《反对本本主义》说「没有调查就没有发言权」。但这句话有一个隐含前提：**你调查的信息必须是最新的。**

在做出方向性判断之前——尤其是"这家公司没有 XX 能力""这个技术它做不了"这类**否定性结论**——必须执行时效性检查：

1. **信息来源的日期是什么？** 半年以上的旧数据、旧问答、旧研报，不能作为否定性结论的唯一依据。
2. **最近一个季度有没有新进展？** 公司可能上一季度刚刚突破、刚刚量产。旧数据只能告诉你"当时没有"，不能告诉你"现在也没有"。
3. **否定性结论比肯定性结论需要更高的证明标准。** "它没有 7N"比"它有 7N"更容易出错——因为"没有"可能是信息滞后，"有"只需要一条最新公告。

**强制规则：当准备说"这家公司没有/做不了/不涉及 XX"时，先搜索"公司名 + XX + 2026"确认最新状态。搜不到或仍显示没有，才可以下否定结论，且必须注明信息来源日期。**

**此次教训**：用 2024-2025 年的董秘问答得出"株冶做不了 7N 铟"的结论，而 2026 年 3 月它已突破 7N 并小批量供货。旧否定结论误导了用户。此类错误不可重复。

---

## 调查铁律二：否定性结论双重验证

**「它没有 XX」比「它有 XX」需要更强的证据。**

肯定性结论的证据门槛：一条最新公告/新闻即可。
否定性结论的证据门槛：必须在最近两周内的多个独立来源中确认"仍然没有/仍然不能/仍然未涉及"。

否定性结论永远绑定三个要素：
- 结论本身（"目前没有 7N 产品"）
- 信息来源日期（"2025 年 5 月 21 日董秘问答"）
- 排除新进展的声明（"已搜索 2026 年 6 月最新信息，未见突破性进展"）

如果无法完成第三步——**那就不要说"没有"。说"截至 XX 日期没有，最新状态待确认"。**

## 调查铁律三：分析有效期——分析不是一次性的

每份分析报告必须标注**数据截止日期**。从截止日期算起：

- 超过 **两周** 未更新的分析 → 涉及关键判断时，必须先刷新数据再引用
- 超过 **一个月** 未更新的分析 → 机构目标价、产能数据、管理层变动等信息大概率已过期
- 超过 **一个季度** 未更新的分析 → 必须重新跑完整框架

**财务数据（季报）只是分析的起点，不是终点。** 从财报发布日到当前之间，公司可能发生了新产品突破、管理层变动、重大项目立项——这些不在财报里，但足以推翻基于财报的判断。每次分析必须补充搜索：公司名 + 最新进展 + 当前月份年份。
