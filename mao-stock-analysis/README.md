# 毛选炒股 · 矛盾论分析框架

> 「谁是我们的敌人？谁是我们的朋友？这个问题是革命的首要问题。」
> —— 换成股票就是：哪是主要矛盾？哪是次要矛盾？这个问题是赚钱的首要问题。

---

## 这是什么

把《实践论》《矛盾论》《论持久战》的精华思想变成一套**可操作的股票分析工具**。

不是一个书单。不是一个读后感。是一个能直接用、能重复用的分析框架。

---

## 它怎么分析股票

不是看K线。不是听消息。是先搞清楚三件事：

**第一，这只股票当前的主要矛盾是什么？**

一只股票任何时候都有一堆矛盾——基本面和技术面打架、多头和空头博弈、内因和外因纠缠。你要做的不是面面俱到，是找到那个**决定了其他一切矛盾的矛盾**。

**第二，它处于持久战的哪个阶段？**

- 战略防御：保存本金，不要被打死
- 战略相持：积蓄认知，等待力量对比逆转
- 战略反攻：集中兵力，打歼灭战

防御阶段做了反攻阶段的事——这就是大多数人亏钱的根源。

**第三，转化条件是什么？**

下了判断不算完。你必须说清楚：什么情况出现时，我改主意？答不上来就是不成熟。

## 使用方式

把 Skill 装到 Claude Code 里，然后直接说：

- 「从矛盾论角度看铭普光磁」
- 「持久战视角看当前大盘」
- 「用毛选思想分析贵州茅台」
- 「XX股票的实践论检验」

它会先搜索真实数据，然后用矛盾矩阵+持久战三阶段+实践论检验输出完整分析。**不存在没有调查就下的判断。**

## 它不是什么

不是荐股工具。不预测明天涨跌。不帮你选代码。

它是一个**让你自己学会用正确方法看股票**的工具。

《实践论》说：「真理的标准只能是社会的实践。」框架好不好，你拿它分析几只看过的股票，看看它说的对不对——这是唯一靠谱的检验方式。
