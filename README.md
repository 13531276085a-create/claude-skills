## 投资决策系统



分析一只股票和分析一场战争，底层逻辑是同一件事。这个 Skill 把《实践论》《矛盾论》《论持久战》《反对本本主义》的精华变成一套可操作的股票分析作战指挥系统。

**核心架构**：
- **九条作战原则**：战略藐视战术重视 / 知己知彼 / 地形决定战术 / 根据地深耕 / 打法选择 / 歼灭战 / 主动权 / 十六字诀 / 战略撤退
- **十四步完整流程**：适用域检查 → 风控四红线 → 紧急熔断 → 数据源规范 → 盲点扫描 → 天时判定 → 分类量化（周期/成长/价值/反转）→ 张新民三问 → 同行对比 → QFII多信号验证 + 对手方分析 → 第一性原理赛道验证 → 李雨青均线判势（五元素标准化输出）→ 矛盾论深度分析（含同一性斗争性）→ 持久战双层仓位 → 卖出三原则 → 信号汇总 → 实践论闭环
- **李雨青均线系统**：5日/10日/20日/62日/133日五线体系 + 金叉死叉 + 生命线 + 量价配合 + 三级强制作战搜索
- **张新民财务三问**：利润质量 / 资产结构 / 资本结构
- **QFII 四维打分**：QFII持仓 + 北向资金 + 机构预测 + 高管增持
- **牛熊联动机制**：天时判定自动联动 PE/ROE/现金流阈值
- **紧急熔断 + 执行断层警报**
- **反转股自动升级**
- **HTML 浅紫主题分析报告**

**触发方式**：「从矛盾论角度看XX股票」「持久战视角看大盘」「用毛选思想分析XX」

**适用场景**：A股/港股/美股个股深度分析、行业赛道筛选、持仓组合诊断、风控体系搭建

## 思维框架引擎

### [mao-zedong-perspective](./mao-zedong-perspective/) —— 毛泽东思维方式

**你不是在介绍框架——你就是在用他的脑子。**

基于《实践论》《矛盾论》《论持久战》《反对本本主义》，用毛泽东的眼睛看问题。穿透表象、抓主要矛盾、短句下判断。

**核心能力**：撕开表面问题 / 在复杂局面中抓住主要矛盾 / 断言式表达 / 没调查就承认没搞清楚

**触发方式**：「毛选思维」「矛盾论视角」「毛式分析」

**适用场景**：深度思考、复杂决策、博弈推演、表达风格训练

---

### [sunyuchen-perspective](./sunyuchen-perspective/) —— 孙宇晨 × 幻夜梦屿 社会心理工具箱

超过 25 个信息源深度调研，融合两套社会心理洞察系统。注意力经济学、人格工程、受众心理操控、情绪去耦、激进实用主义。

五个核心心智模型 + 八条决策启发式。聚焦：怎么获取注意力、怎么影响人、怎么操控博弈心理。

## 视觉创作工坊

### [guizang-ppt-skill](./guizang-ppt-skill/) —— 归藏网页 PPT

生成横向翻页网页 PPT（单 HTML 文件），含 WebGL 背景、章节幕封、数据大字报、图片网格。

**两种风格**：电子杂志 × 电子墨水（衬线 + 流体背景 + 暖色）/ 瑞士国际主义（无衬线 + 网格点阵 + IKB/柠檬黄/柠檬绿高亮）

**触发方式**：「杂志风PPT」「瑞士风PPT」「Swiss Style」「horizontal swipe deck」

---

### [guizang-social-card-skill](./guizang-social-card-skill/) —— 归藏社交卡片

从文章、脚本、截图、字幕中提取内容，生成归藏风格小红书图文和微信公众号封面。3:4 竖版 + 21:9 横版 + 1:1 方形。

**触发方式**：「小红书图文」「Rednote images」「社交卡片」「微信公众号封面」

---

### [frontend-slides](./frontend-slides/) —— 前端幻灯片

零依赖、单文件、动画丰富的 HTML 演示文稿。通过视觉探索而非抽象选择来设计。支持 PPT/PPTX 转换。

---

### [kami](./kami/) —— 排版引擎（紙）

专业文档和产品落地页排版引擎。支持简历、白皮书、作品集、一页纸、信件、幻灯片、落地页。

羊皮纸暖色底 + 靛蓝强调色 + 衬线层级。中文苍耳今楷，英文 Charter，日文游明朝。

**触发方式**：「做PDF」「排版」「一页纸」「白皮书」「作品集」「简历」「落地页」

## 内容生产工具

### [long-tail-traffic-strategy](./long-tail-traffic-strategy/) —— 长尾流量策略

挖掘长尾词、制定SEO和小红书搜索流量选题、分析搜索意图、寻找需求缺口、撰写爆款文案。

**触发方式**：「长尾词」「找词」「SEO选题」「小红书搜索流量」「爆款选题」

---

### [humanizer](./humanizer/) —— AI 痕迹去除

基于 Wikipedia "Signs of AI writing" 指南，检测和修复 AI 生成文本的机器味。夸张象征、推广语、破折号过度、AI 高频词、被动语态、填充语。

---

### [videocut](./videocut/) —— 视频处理套件

高清导出（2-pass编码+锐化）、字幕生成（火山引擎转录→纠错→烧录）、口播剪辑（口误识别）、自进化（反馈记录）、环境安装。

## 命理分析系统

### [mingli](./mingli/) —— 多维命理分析

整合**紫微斗数、八字（四柱）、印度占星**三种命理体系。通过交叉验证、逐步推理、质疑检验生成结构化报告。

支持单维度和多维度两种模式。多维度含三维对照表、交叉验证矩阵、趋势曲线图。

**触发方式**：「算命」「命理」「紫微」「八字」「流年」「大运」「排盘」

## 生产力基座

### [huashu-nuwa](./huashu-nuwa/) —— 女娲 · Skill 造人术

输入人名或主题 → 自动深度调研 → 思维框架提炼 → 生成可运行的人物 Skill。

6 个并行 Agent（著作/对话/表达/他评/决策/时间线）→ 框架提炼 → 质量验证 → 双Agent精炼。

**触发方式**：「造skill」「蒸馏XX」「XX的思维方式」「做个XX视角」

---

### [book-to-skill](./book-to-skill/) —— 书籍转 Skill

将 PDF、EPUB、DOCX、HTML、Markdown、RTF、MOBI/AZW 格式书籍转换为结构化 Agent Skills。提取框架、心智模型、原则和反模式。

帮助发现和安装 Agent Skills。当你问「怎么实现X」「有没有skill可以做Y」时自动触发。
