## 投资决策系统

### [mao-stock-analysis](./mao-stock-analysis/) —— 毛式作战体系 v3.0

**分析战场就是分析股票。**

完整作战指挥系统。六条毛式作战原则、三红线风控、十步作战流程、卖出三纪律。

**核心框架**：
- **知己知彼**：每次分析前先做己方审计——资金性质、回撤承受、持有期限、行业认知
- **天时判定**：沪深300在年线之上？成交额>8000亿？北向在买？
- **根据地深耕**：选定1-2个行业反复作战，重仓限定在根据地内
- **打法选择**：阵地战（1-3年）vs 运动战（1-3月），仓位规则完全不同
- **歼灭战**：集中兵力，不撒胡椒面
- **主动权**：每次开仓前检查——是你选的时机，还是市场逼你的？

**十步流程**：风控红线 → 知己审计 → 天时判定 → 根据地检查 → 分类+量化初筛（周期/成长/价值）→ 张新民三问（利润质量/资产结构/资本结构）→ 同行横向对比 → QFII多信号验证+对手方分析 → 第一性原理赛道验证 → 矛盾论判定时机（转化条件绑时间轴）→ 持久战仓位管理（波动率打折+相关性检查）→ 卖出三纪律（止损/移动止盈/逻辑证伪）→ 实践论反馈闭环 → HTML报告输出

**触发方式**：直接说「从矛盾论角度看XX股票」「持久战视角看当前大盘」「用毛选思想分析XX」

**适用场景**：A股/港股/美股个股深度分析、行业赛道筛选、持仓组合诊断、风控体系搭建

## 思维框架引擎

### [mao-zedong-perspective](./mao-zedong-perspective/) —— 毛泽东思维方式

**你不是在介绍框架——你就是在用他的脑子。**

基于《实践论》《矛盾论》《论持久战》《反对本本主义》，用毛泽东的眼睛看问题。

**核心能力**：
- 不被表面问题迷惑——先撕开问题的前提，再决定怎么回答
- 在复杂局面中抓住主要矛盾——一百个问题里只有一个是决定性的
- 短句、比喻、下判断——不说「可能」「也许」「一方面另一方面」
- 没调查过的事承认没搞清楚——不编造

**触发方式**：提到「毛选思维」「矛盾论视角」「毛式分析」「用毛泽东的思维方式」

**适用场景**：穿透表象的深度思考、复杂决策分析、博弈推演、表达风格训练

---

### [sunyuchen-perspective](./sunyuchen-perspective/) —— 孙宇晨 × 幻夜梦屿 社会心理工具箱

基于超过25个信息源深度调研，融合两套社会心理洞察系统。

**五个核心心智模型**：
1. 注意力货币化链——获取注意力 → 人格化注意力 → 变现注意力
2. 情绪操作系统——对内的情绪去耦 + 对外的情绪利用
3. 激进实用主义谱系——防守型（在既有系统里爬到顶端）→ 进攻型（重新定义游戏规则）
4. 道德去耦与受众操控——道德评价是操控受众的最有效杠杆
5. 认知框架之战——最深的竞争是定义的竞争

**八条决策启发式**：注意力审计、赌场vs考场识别、情绪燃料化、受众心理画像先行、框架先行原则、增量vs存量识别、情绪去耦检查、跟随资本流

**适用场景**：市场行为分析、传播策略设计、竞争博弈、用户心理洞察

## 视觉创作工坊

### [guizang-ppt-skill](./guizang-ppt-skill/) —— 归藏网页 PPT

**生成横向翻页网页 PPT，单 HTML 文件，零依赖。** 含 WebGL 背景、章节幕封、数据大字报、图片网格等模板。

**两种风格**：
- 电子杂志 × 电子墨水：衬线字体 + 流体背景 + 暖色调
- 瑞士国际主义：无衬线 + 网格点阵 + IKB / 柠檬黄 / 柠檬绿 / 安全橙高亮

**触发方式**：提到「杂志风PPT」「瑞士风PPT」「Swiss Style」「horizontal swipe deck」

---

### [guizang-social-card-skill](./guizang-social-card-skill/) —— 归藏社交卡片

生成归藏风格小红书图文和微信公众号封面。从文章、脚本、截图、字幕、照片中提取内容，自动排版为社交卡片。

**输出格式**：3:4 竖版图文 / 21:9 横版封面 / 1:1 方形封面

**触发方式**：「小红书图文」「Rednote images」「社交卡片」「微信公众号封面」

---

### [frontend-slides](./frontend-slides/) —— 前端幻灯片

通过视觉探索而非抽象选择，创建动画丰富的 HTML 演示文稿。支持 PPT/PPTX 转换为网页格式。

**核心理念**：零依赖、单文件、浏览器原生运行。用"给你看"代替"跟你说"。

---

### [kami](./kami/) —— 排版引擎（紙）

**纸 · かみ**——让好内容有好排版。专业文档和产品落地页排版引擎。

**支持类型**：简历、白皮书、作品集、一页纸、信件、幻灯片、落地页

**视觉语言**：羊皮纸暖色底 + 靛蓝强调色 + 衬线层级。中文用苍耳今楷，英文用 Charter，日文用游明朝。

**触发方式**：「做PDF」「排版」「一页纸」「白皮书」「作品集」「简历」「落地页」

## 内容生产工具

### [long-tail-traffic-strategy](./long-tail-traffic-strategy/) —— 长尾流量策略

挖掘长尾关键词、制定SEO和小红书搜索流量选题、分析用户搜索意图、寻找需求缺口、撰写长尾词爆款文案。

**核心能力**：关键词需求分析、搜索意图分类、信息增量评估、内容矩阵规划

**触发方式**：「长尾词」「找词」「SEO选题」「小红书搜索流量」「爆款选题」

---

### [humanizer](./humanizer/) —— AI 痕迹去除

去除 AI 生成文本的机器味，使其更自然。基于 Wikipedia "Signs of AI writing" 完整指南。

**检测与修复**：夸张象征、推广语、表面的-ing分析、模糊归属、破折号过度使用、三段论、AI常用词、被动语态、否定排比、填充语

---

### [videocut](./videocut/) —— 视频处理套件

**五个子技能**：
- **高清导出**：2-pass编码 + 锐化，画质匹配或超越原片
- **字幕生成**：火山引擎转录 → 词典纠错 → 审核 → 烧录
- **口播剪辑**：口误识别，生成审查稿和删除任务清单
- **自进化**：记录用户反馈，更新方法论和规则
- **环境安装**：安装依赖、配置 API Key、验证环境

## 命理分析系统

### [mingli](./mingli/) —— 多维命理分析

整合**紫微斗数、八字（四柱）、印度占星**等多种命理体系。

**核心机制**：各体系独立完整分析 → 大运/流年三维对照表 → 交叉验证矩阵 → 逐步推理与质疑检验 → 趋势曲线图

**两种模式**：
- 单维度输入 → 直接按该体系的专属框架输出完整分析
- 多维度输入 → 五步完整流程（独立分析 → 时空对照 → 交叉验证 → 推理质疑 → 趋势曲线）

**触发方式**：「算命」「命理」「紫微」「八字」「流年」「大运」「排盘」

## 生产力基座

### [huashu-nuwa](./huashu-nuwa/) —— 女娲 · Skill 造人术

输入人名或主题，自动**深度调研 → 思维框架提炼 → 生成可运行的人物 Skill**。

**两种入口**：
- 明确人名 → 直接蒸馏（6个并行Agent：著作/对话/表达/他评/决策/时间线）
- 模糊需求 → 诊断推荐（从需求反推最合适的蒸馏对象）

**生成的 Skill 包含**：心智模型、决策启发式、表达DNA、价值观、反模式、内在张力、智识谱系、诚实边界

**触发方式**：「造skill」「蒸馏XX」「XX的思维方式」「做个XX视角」

### [book-to-skill](./book-to-skill/) —— 书籍转 Skill

将 PDF、EPUB、DOCX、HTML、Markdown、RTF、MOBI/AZW 格式的书籍转换为结构化 Agent Skills。

## 安装指南

### 前提条件

已安装 [Claude Code](https://docs.anthropic.com/en/docs/claude-code/overview)。

### 方式一：Git 克隆（推荐）

```bash
git clone https://github.com/13531276085a-create/claude-skills.git
cp -r claude-skills/* ~/.claude/skills/
```

### 方式二：单独安装某个 Skill

```bash
# 只装股票分析
git clone https://github.com/13531276085a-create/claude-skills.git --depth 1
cp -r claude-skills/mao-stock-analysis ~/.claude/skills/
```

### 方式三：下载 Release

访问 [Releases](https://github.com/13531276085a-create/claude-skills/releases) 下载最新版本，解压到 `~/.claude/skills/`。

### 验证安装

在 Claude Code 中输入对应触发词，Skill 应自动激活。输入 `/skills` 可查看已安装列表。

## 使用场景示例

### 场景一：深度股票分析

```
> 从矛盾论角度看紫金矿业

→ mao-stock-analysis 自动激活
→ 跑完十步作战流程
→ 生成 HTML 分析报告
```

### 场景二：毛式思维方式分析问题

```
> 用毛选思维分析我该不该接这个offer

→ mao-zedong-perspective 自动激活
→ 撕开表面问题，找主要矛盾
→ 给出不含糊的判断
```

### 场景三：制作演讲 PPT

```
> 帮我做一个瑞士风格的网页PPT，主题是AI行业展望

→ guizang-ppt-skill 自动激活
→ 生成横向翻页 HTML 文件
```

### 场景四：创建人物 Skill

```
> 蒸馏巴菲特的思维方式，做一个skill

→ huashu-nuwa 自动激活
→ 6个并行Agent深度调研
→ 提炼心智模型 → 生成可运行Skill
```

### 场景五：从零到完整内容

```
用 long-tail-traffic-strategy 找选题
  → 用 mao-zedong-perspective 深度思考文章结构
  → 写完后用 humanizer 去AI味
  → 用 kami 排版成精致的PDF
  → 用 guizang-social-card-skill 生成社交卡片推广
```

### 场景六：命理分析

```
> 帮我排八字看流年

→ mingli 自动激活
→ 支持紫微斗数、八字、印占多体系交叉验证
```
